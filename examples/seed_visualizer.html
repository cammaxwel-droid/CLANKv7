03 / UNDER THE SWITCHES

Follow the seed, not a hunch.

These equations run once on the seed. TriFlow then generates the sequence from the effective seed.

  1. Original seed

    0x0123456789abcdef

    The transformation pipeline appears when the seed engine is ready.

64 bits, no extra luggage.

Arithmetic wraps modulo 2⁶⁴: keep the lowest 64 bits, discarding overflow. Decimal and hex are just two ways to write the same integer.

Rearrange. Compare. Repeat.

A rotation moves bits around and wraps them at the ends. XOR sets a bit to 1 where its two inputs differ. The pipeline counts changed bits between each stage’s input and output.

More change ≠ better randomness.

These experiments add no entropy and can merge seeds. Cross-feed alone maps both 0 and 2⁶⁴ − 1 to 0; Rotate fold and Cross-feed each leave zero unchanged. More changed bits, a busy plot, or near-zero correlation proves neither quality nor security.

Deterministic by design. Experimental by nature. This is a PRNG, not true randomness. The C++ core is unchanged.

Visual exploration is not certification. Not for cryptographic keys, passwords, or live gambling.
