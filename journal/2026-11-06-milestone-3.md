# 2026-11-06 - milestone 3: deterministic sampling helpers

## What changed

Added `clank-sampling-v1` methods to the TypeScript RNG without changing the
raw `triflow-v1` sequence. Bounded integers use rejection sampling rather than
simple modulo reduction, so remainder values do not receive extra outcomes.
The helper set includes half-open bigint intervals, 53-bit floats, rational
probabilities, weighted selection, and a copy-returning Fisher-Yates shuffle.

All helper arguments are checked before consuming output or taking a
deterministic shortcut. Unit-weight totals and integer bounds are capped at
`2^32`; degenerate probabilities and choices, one-value intervals, and shuffles
of zero or one item consume no raw words. The public declarations and package
docs identify the helper contract separately from the frozen engine.

## Verification

`npm test` passed after implementation: strict compilation, public declaration
checks, the original raw-vector/checkpoint checks, and 11 Node tests. The
deterministic-engine tests establish repeatability and boundary behavior, not
statistical quality, unpredictability, or suitability for security-sensitive
uses. Full cross-language conformance remains to be rerun after final edits.
