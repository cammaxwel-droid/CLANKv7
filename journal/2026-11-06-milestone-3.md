# 2026-11-06 - milestone 3: game sampling helpers

## What changed

Added the separately versioned `clank-sampling-v1` API as `createSampler`,
wrapping the existing `triflow-v1` raw engine without changing its sequence.
The helper set includes rejection-sampled bounded integers through `2^32`,
half-open integer intervals, 53-bit floats, integer probabilities and weights,
array picking, and copy-based Fisher-Yates shuffling.

Inputs are validated before sampling. Deterministic cases skip draws, and
bounded sampling has no retry cutoff or biased fallback. The sampling guide
records these rules because the number of draws affects replay.

## Verification

`npm test` passed: strict source build, declaration checks, and all 18 Node
tests, including fixed raw-engine vectors and the new helper edge cases.
`npm run verify` also passed the full existing C++/Python/TypeScript checks:
87 seeds, 870,000 raw words per engine, and 1,044 checkpoints. This confirms
the raw sequence and its frozen fixtures remain unchanged. The statistical
smoke checks passed as well, but do not certify randomness or security.
